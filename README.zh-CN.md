# 移动机械执行接口

[English](README.md) · **简体中文**

**Mobile Machine Actuation Interface（MMAI）**：用于为现有机电式、电液式移动机械
增加遥控或自主控制能力的软硬件接口。

![MMAI 命令、执行与反馈架构](docs/architecture.svg)

MMAI 将上层控制器连接到现有机械的转向、行驶、辅助功能及可获取的状态反馈。
本仓库通过原理图、固件、接口代码和开发历史，展示工程思路与实现路径。源码保留了
ECU 硬件、通信和执行接口的设计选择，应结合具体电路和实现阅读。

## 功能

- 接收遥控或自主控制软件的命令。
- 校验命令，管理控制权、超时和输出使能。
- 将命令映射到继电器、CAN 执行器或 PWM 驱动的液压阀线圈等电气接口。
- 采集机械与执行器状态，并向上层返回反馈。
- 使底层机械行为能够独立于规划算法被理解。

这一架构可适配清扫车、压路机、农业机械、作业车辆及其他移动设备。执行器、接线、
反馈与停止行为均取决于具体机械。模拟量命令输出或额外串行接口属于可选适配路径，
并不表示仓库中的每块电路板都具有这些能力。

## 架构

机械接口 ECU 位于命令来源与实际机械之间。转向、行驶和辅助 I/O 分别适配，状态
反馈经 ECU 返回上层。原有人工操作与机械联锁也是整合时必须考虑的部分。

导航、感知和路径规划不属于核心执行接口的边界。当前实现聚焦底层执行和状态反馈。
参见英文[架构说明](docs/architecture.md)与
[接口说明](docs/interfaces.md)。

## 建议阅读顺序

1. 阅读英文[硬件指南](docs/hardware.md)，并打开相应原理图。
2. 按[固件指南](docs/firmware.md)追踪一条命令：解析、控制策略、机械映射、物理驱动。
3. 反向追踪反馈，注意单位和有效性标志。
4. 根据[项目历史](docs/PROVENANCE.md)比较早期版本。
5. 用[移植指南](docs/porting-guide.md)描述另一种机械的接入方法。

H563 示例包含 Ethernet 命令/状态协议、CAN 接口、继电器触点输出、带电流采样的
PWM 阀驱动，以及模拟量、开关量和脉冲输入。其通信协议和 I/O 分配是具体实现的
选择，不是适用于所有机械的统一 API。

## 安全与台架探索

本项目属于实验性工程资料，不是经过功能安全认证的控制器或可直接安装的车辆改装
产品。实际部署需要针对机械开展工程设计。电气探索应先使用隔离信号和模拟负载；
连接执行器前，应理解启动、命令中断、人工控制和急停行为。参见英文
[安全说明](docs/SAFETY.md)。
