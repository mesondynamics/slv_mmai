# Reporting security issues

For a suspected credential exposure, unsafe remote-command path, or vulnerability
in firmware update or device-access handling, contact a repository maintainer
privately using their existing repository contact information. Yuan Mei's
repository author contact is [yuan.mei@gmail.com](mailto:yuan.mei@gmail.com).

Include the affected revision and component, a description of the behavior, and
enough context to reproduce it without operating machinery. Redact credentials,
private keys, customer information, and device-access material from reports.
Avoid posting working secrets in a public issue.

Historical snapshots are engineering records and do not imply an active security
support period. Physical integration concerns should also be evaluated against
the [safety guidance](docs/SAFETY.md).
